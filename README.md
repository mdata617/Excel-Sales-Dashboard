# Excel Sales Performance Dashboard

An Excel-based sales analysis project focused on tracking sales executive performance and progress toward sales targets.

## Project Overview

This workbook contains 141 sales records and compares employee sales performance across different regions. It includes a raw-data sheet, a reference dashboard (`DASHBOARD`), and my own dashboard (`My Dashboard`).

## Key Analysis

- **Total Sales:** Summarizes each sales executive's sales across five days.
- **Target Hit %:** Measures sales achieved as a percentage of the target.
- **Away From Target %:** Shows the percentage remaining to reach the target.
- **Employee Performance:** Highlights top and lower-performing sales executives.

## Tools and Techniques

- Microsoft Excel
- Excel formulas (`SUM` and percentage calculations)
- Sales performance reporting and dashboard analysis

## Workbook Sheets

| Sheet | Description |
| --- | --- |
| `RAW DATA` | Employee, region, daily sales, targets, and calculated metrics |
| `My Dashboard` | My sales performance dashboard |
| `DASHBOARD` | Reference dashboard used during learning |

## How to View

1. Download the Excel workbook from this repository.
2. Open it in desktop Microsoft Excel for the best experience.
3. Open **My Dashboard** to view my work, and **RAW DATA** to inspect the calculations.

> Note: This is an Excel learning project. The `DASHBOARD` sheet is a reference dashboard; `My Dashboard` is my own work.
